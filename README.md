## Backend Server Port Configuration

To customize which port the backend Express server listens on, create or edit the `.env` file located in `tasksphere_backend/` and add:
```
PORT=3001
```
Replace `3001` with your desired port. If `PORT` is not set in `.env` or your environment, the backend will default to port 3001.

Restart the backend server after changing the `.env` file.
